# Day 1 — Python Foundations

Learning Python basics coming from a JavaScript background. Code lives in `python_basics.py`.

## Tasks

**Task 1 — Variables, Types & Operators**
Declared `int`, `float`, `str`, `bool`, `None` and printed types. Practiced arithmetic (`+ - * / // % **`), comparison, and logical operators (`and`, `or`, `not`).

**Task 2 — Conditionals**
Built a grading function (`Excellent` / `Very Good` / `Good` / `Pass` / `Fail`) based on marks, with range checks and handling for invalid input outside 0–100. Tested against boundary values.

**Task 3 — Loops**
Used `for` and `while` loops to: print 1–100, print evens, sum 1–100, generate a multiplication table (n=7), and find the max value in a list manually (no `max()`).

**Task 4 — Collections**
Practiced lists (index, append, remove), tuples (indexing + immutability), sets (duplicate removal), and dictionaries (update value, loop through keys/values/items).

**Task 5 — Mini Project: Student Analyzer**
Processed a list of student dictionaries to calculate total students, average marks, highest/lowest marks (with names), and pass/fail counts — including handling an empty student list.

## Notes
Coming from JS, main differences noticed: no `++`/`--` operators, `len()` instead of `.length`, floor division (`//`), and Python's `and`/`or`/`not` keywords instead of `&&`/`||`/`!`.
